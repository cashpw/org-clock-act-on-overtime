#+title: org-clock-act-on-overtime

Invoke custom functions when the current org-clock is overtime!

Overtime is based:

1. Scheduled duration (for example: SCHEDULED: <2025-05-01 Thu 10:00-11:00> -> =60= minutes)
1. =Effort= property

* Usage

#+begin_src emacs-lisp
(defun my/notify-overtime ()
  "Let me know when I'm over my planned clock time."
  (message "Overtime!"))

(add-to-list 'org-clock-act-on-overtime-fns #'my/notify-overtime)
(org-clock-act-on-overtime-mode 'enable)
#+end_src
